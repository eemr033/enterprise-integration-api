# Enterprise Integration API

A modular backend API designed for enterprise system integrations.

This project demonstrates how to build a scalable integration layer
using modern backend architecture patterns.

## Architecture

- Clean Architecture
- Hexagonal Architecture (Ports and Adapters)
- Modular Domain Design
- Generic Query Engine
- Secure CRUD operations

## Features

- JWT Authentication
- Refresh Token Strategy
- Rate Limiting
- Audit Logging
- Generic Query Engine
- ERP Integration Layer
- Modular Architecture

## Technologies

- .NET 8
- ASP.NET Core
- Entity Framework
- Oracle Database
- PostgreSQL
- Redis
- JWT Authentication

## Purpose

This project was built for learning and portfolio purposes to demonstrate
backend architecture patterns for enterprise integrations.
